# API reference

Interactive documentation is generated by FastAPI: **`/docs`** (Swagger UI), **`/redoc`**, **`/openapi.json`**.
This page is the human-oriented summary. All JSON, UTF-8.

## Conventions

**Authentication.** `Authorization: Bearer <token>` where the token comes from `POST /api/v1/auth/login`
(HS256 JWT, 60 min by default, `iss`/`exp`/`sub` required, algorithm pinned server-side).

**Errors** always use one envelope:
```json
{"error": {"code": "alias_conflict", "message": "That alias is already in use.",
           "request_id": "9b1f…", "details": [{"loc": ["body","custom_alias"], "message": "…", "type": "…"}]}}
```
`details` appears for validation errors only. Submitted values are never echoed back (they may be passwords).
Every response carries `X-Request-ID`; send your own (8–64 chars `[A-Za-z0-9._-]`) to correlate logs.

| status | codes |
|---|---|
| 401 | `unauthorized`, `invalid_token`, `token_expired`, `invalid_credentials` |
| 404 | `not_found`, `url_not_found` (also returned for URLs owned by someone else), `link_not_found` |
| 409 | `alias_conflict`, `email_taken` |
| 410 | `link_gone` |
| 413 | `payload_too_large` (body limit 64 KiB by default) |
| 422 | `validation_error` |
| 429 | `rate_limited` – with `Retry-After` |
| 503 | `service_unavailable` (PostgreSQL unavailable), `id_space_exhausted` |

**Rate limiting.** Sliding window (default 60 s). Responses that pass through a limiter include
`X-RateLimit-Limit` and `X-RateLimit-Remaining`; 429 adds `Retry-After` (whole seconds).

| category | default | key |
|---|---|---|
| redirect | 120 / min | client IP |
| create (anonymous) | 10 / min | client IP |
| create (signed in) | 60 / min | user id |
| auth (register / login / change-password) | 10 / min | client IP |

Client IP comes from the TCP peer. `X-Forwarded-For` is honoured **only** when the peer is inside
`TRUSTED_PROXIES`, walking the header right-to-left past trusted hops.

## Redirect

### `GET /{short_code}`
| status | meaning |
|---|---|
| 302 | `Location: <destination>`, `Cache-Control: no-store` |
| 404 | unknown (or malformed) code |
| 410 | expired or deactivated |
| 429 | rate limited |

Codes are `[A-Za-z0-9_-]{3,32}`, case-sensitive. Reserved words cannot be used as aliases.

## Authentication

| method & path | body | success |
|---|---|---|
| `POST /api/v1/auth/register` | `{email, password(8–128)}` | 201 `{id, email, created_at}` |
| `POST /api/v1/auth/login` | `{email, password}` | 200 `{access_token, token_type, expires_in, user}` |
| `GET /api/v1/auth/me` | – | 200 user |
| `POST /api/v1/auth/change-password` | `{current_password, new_password}` | 204 |
| `DELETE /api/v1/auth/me` | – | 204 (deletes the account, all links and analytics) |

Unknown email and wrong password are indistinguishable (same message, comparable timing).
Unknown JSON fields are rejected with 422 on every request model.

## URLs

### `POST /api/v1/urls` (anonymous or authenticated)
```json
{"original_url": "https://example.com/a/long/path",
 "custom_alias": "spring-sale",
 "expires_at": "2026-12-31T23:59:00Z"}
```
`custom_alias` (optional): 3–32 of `[A-Za-z0-9_-]`, case preserved, not reserved → otherwise 422; taken → **409**.
`expires_at` (optional): timezone-aware, in the future, within `MAX_EXPIRY_DAYS`.
`original_url`: http/https only, no credentials, ≤ 2048 characters, may not point at this service.
Without an alias a 7-character code is generated. **201**:
```json
{"short_code":"abe0gaz","short_url":"http://localhost:8000/abe0gaz","original_url":"https://example.com/…",
 "created_at":"…","expires_at":null,"is_active":true,"is_expired":false,"total_clicks":0,"is_owned":true}
```

### `GET /api/v1/urls?limit=20&cursor=…&q=…`
Your links, newest first. `limit` 1–100. `q` matches short code or destination (substring, case-insensitive).
Keyset pagination: pass the previous response's `next_cursor` (`null` on the last page).
```json
{"items": [ /* URL objects */ ], "next_cursor": "aWQ6MTIz"}
```

### `GET /api/v1/urls/{short_code}` · `PATCH` · `DELETE`
`PATCH` body: `{"is_active": false}` and/or `{"expires_at": "<ISO>" | null}` (explicit `null` clears the expiry).
`DELETE` → 204. All three return **404** for links you do not own.
Every mutation updates or invalidates the Redis entry before returning.

## Analytics (owner only; 404 otherwise)

Counts are eventually consistent: a click is visible after the worker flushes (≈ 5 s by default).

| path | response |
|---|---|
| `GET /api/v1/analytics/{code}` | `{total_clicks, clicks_today, clicks_last_7_days, clicks_last_30_days}` (UTC days) |
| `GET /api/v1/analytics/{code}/daily?from=YYYY-MM-DD&to=YYYY-MM-DD` | `{from, to, total, points:[{date, clicks}]}` – one point per day, zeros included; default last 30 days; max range 366 days; `from > to` → 422 |
| `GET /api/v1/analytics/{code}/browsers?limit=10` | `{total, items:[{name, clicks, percentage}]}` |
| `…/devices` · `…/os` · `…/referrers` · `…/countries` | same shape. `countries` is empty unless a GeoIP database is configured |

## Dashboard

`GET /api/v1/dashboard/summary` →
`{total_urls, active_urls, total_clicks, average_clicks_per_url, clicks_last_14_days:[…], top_links:[…], recent_urls:[…]}`

## Operations

| path | |
|---|---|
| `GET /health/live` | process is up (always 200) |
| `GET /health/ready` | PostgreSQL **required** (503 if down). Redis is optional: if any Redis client fails the response is **200** with `"status": "degraded"` |
| `GET /metrics` | Prometheus text format |

### Prometheus metrics
API: `redirect_requests_total`, `redirect_success_total`, `redirect_errors_total{reason}`,
`redirect_latency_seconds` (histogram), `cache_hits_total`, `cache_misses_total`, `cache_negative_hits_total`,
`cache_hit_ratio`, `cache_errors_total`, `cache_corrupt_total`, `rate_limit_rejections_total{category}`,
`rate_limit_errors_total{mode}`, `url_creation_requests_total{result}`, `click_events_enqueued_total`,
`stream_enqueue_failures_total{reason}`, `http_request_duration_seconds{method,route,status}`,
`db_query_duration_seconds` (histogram).

Worker (port `WORKER_METRICS_PORT`, default 9101; cleanup worker on +1):
`worker_events_processed_total`, `worker_events_duplicate_total`, `worker_events_dropped_total{reason}`,
`worker_batches_total`, `worker_batch_failures_total`, `worker_batch_duration_seconds`,
`worker_reclaimed_events_total`, `worker_stream_lag`, `worker_stream_pending`, `worker_stream_length`,
`cleanup_deleted_total{kind}`.

Metrics are per process (one uvicorn process per container); scrape every replica.
